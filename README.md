## 📌 Projects / 项目

### [word-lookup-cli](https://github.com/Elisha-Luo/word-lookup-cli)

**A command-line English dictionary powered by DeepSeek.** Type a word and get its part of speech,
Chinese definition and an example sentence. Supports looking up several words at once, and saves
every query to a local history file.

**命令行英语单词查询工具。** 输入单词即可得到词性、中文解释和例句。支持一次查询多个单词，查询记录自动保存到本地。

`Python` · `openai SDK` · `CLI`

### [word-lookup-web](https://github.com/Elisha-Luo/word-lookup-web)

**The same tool, as a web app.** Built with Flask and hand-written CSS — no frontend framework,
no copied templates.

**同一个工具，做成了网页版。** 用 Flask 加手写的 CSS 实现，没有引入任何前端框架，也没有套用现成模板。

`Python` · `Flask` · `Jinja2` · `CSS`
